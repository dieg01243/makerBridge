# Cómo correr el frontend de MakerBridge
 
Pasos para levantar el proyecto en local, partiendo de estar parado en la raíz del repo `makerBridge`.
 
## Requisitos
 
- Node.js 18 o superior instalado (`node -v` para confirmar)
## Pasos
 
```bash
cd frontend-MB
#solo la primera vez o si cambia el package-lock.json
npm install 
npm run dev
#abrimos la URL con ctr + c
```
